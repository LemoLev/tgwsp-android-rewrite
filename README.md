# Сборка из исходников

Данный проект использует оригинальный скрипт
python [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) для создания локального MTProto-прокси
на устройстве Android - что дает все плюсы и особенности работы оригинального скрипта.

Для работы Python-кода используется Python SDK for
Android [chaquopy](https://github.com/chaquo/chaquopy).
Для создания bridge между Java-кодом и Python используется _Static Proxy_, который описывается в
_main.py_ для вызова и на его основе генерируется код на Java, чтобы его можно было вызывать в
дальнейшем в коде самого приложения. Поэтому если вы первый раз запускаете приложение, у вас не
будет этого класса - просто выполните сборку проекта = gradle:build. Для работы генерации
_Static Proxy_ необходимо наличие установленного Python на машине для сборки.

Обратите внимание, что код Python компилируется в формат _.py_ для более быстрого запуска
приложения.
Если компиляция байт-кода пройдет успешно, исходные файлы .py не будут включены в APK, если только
они не охвачены параметром _extractPackages_. Однако это предотвращает появление текста исходного
кода в трассировках стека, поэтому во время разработки вы можете отключить эту функцию.

Обратите внимание, что отключение компиляции байт-кода будет приводить к компиляции кода на целевом
устройстве и занимать больше памяти. Компиляция байт-кода включена по умолчанию.

Для установки зависимостей **chaquopy**, возможно, потребуется VPN.

Также для работы необходимо наличие установленного Android NDK.

## Имеющиеся ограничения

На данный момент MTProto-прокси в мобильных сетях может вообще не работать, стабильная работа
наблюдается в WiFi-сетях, однако, иногда тоже могут возникать проблемы - попробуйте перезапустить
прокси или подождать какое-то время (на основании наблюдения как пользователя).

Особенно рекомендую [ознакомиться](https://github.com/Flowseal/tg-ws-proxy/issues/389) с популярными
вопросами/ответа по этому прокси и как его настраивать. 

НЕ ДОБАВЛЯЙТЕ IP В МАППИНГ ЕСЛИ НЕ ЗНАЕТЕ, ЧТО ОН ДЕЛАЕТ - DC:IP - почему именно такие версии описано
в блоке _ознакомиться_.

## Windows

Сначала,

1. Нажмите на Win+R
2. Введите cmd

Затем скачайте или склонируйте репозиторий. (Если у вас установлен git, то введите команду
`git clone https://github.com/LemoLev/tgwsp-android-rewrite.git`, а если нет, то скачайте с главной
страницы через кнопку "Code"->"Download ZIP" и разархивируйте его куда-то)

После этого, в cmd, перейдите в папку с репозиторием

1. Если вы клонировали через git, то просто `cd tgwsp-android-rewrite`
2. Если вы скачивали через сайт, то вам нужно найти то место, где лежит папка репозитория и ввести
   `cd tgwsp-android-rewrite`.

Для начала сборки, установите джаву с [java.com](https://www.java.com/ru/download/)
После установки, удостоверьтесь, что вы сделали всё правильно, сделав:

1. Введите `echo %JAVA_HOME%`
2. Если вывелось что-то похожее на путь, то вы всё сделали правильно и можете переходить к самой
   сборке. (НЕ ЗАКРЫВАЙТЕ CMD!)

В открытом вами cmd, вводите "gradlew build".
